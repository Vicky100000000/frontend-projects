## Oasis Modern Hotel Booking Confirmation

A responsive hotel booking confirmation page built with HTML, CSS, and JavaScript.

## Project Overview

This project recreates a hotel booking confirmation interface with a branded sidebar, layered booking cards, guest information, Wi-Fi details, and useful booking actions.

## Planned Features

- Responsive desktop, tablet, and mobile layouts
- Collapsible navigation menu on smaller screens
- Receipt and host-note card hover animations
- Wi-Fi password copy button
- Print receipt functionality
- Add-to-calendar functionality
- Booking information loaded from a JSON file
- Keyboard-friendly focus states
